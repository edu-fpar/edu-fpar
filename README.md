### 🎓 Interactive teaching tools · Outils pédagogiques interactifs

**Tools to teach differently: learners handle things, try, and understand.**
Built with AI by a trainer, for teachers, trainers and their students. Everything runs in the browser: no install, no account, no data sent anywhere.

🇫🇷 [Version française plus bas](#-en-français)

👤 Main account: [fxpar](https://github.com/fxpar) · 💼 [LinkedIn](LIEN_LINKEDIN_A_COMPLETER)

| Tool | For whom | What learners discover |
|---|---|---|
| [Star Nav](https://edu-fpar.github.io/star-nav/#level-1) | Children aged 8+, parents, primary teachers | Gravity and trajectories without a single equation: 25 levels of space navigation. |
| [MicroLearn Studio](https://edu-fpar.github.io/micro-learning-app/) | Trainers, course designers | Turn a Markdown course into an interactive slideshow, exportable as a SCORM package for any LMS. |
| [Perspective Grid](https://edu-fpar.github.io/perspective-grid/) | Teachers in any subject | How different viewpoints rank the same items differently. Any AI can build a grid for you. |
| [Capital Lab](https://edu-fpar.github.io/capital-lab/) | Business schools, finance, corporate law | How you can control a company while being a minority shareholder: ownership chains, pacts, double voting rights. |
| [Family photos](https://edu-fpar.github.io/docs-badge/) | Genealogists, teachers annotating scanned work | Sort, de-duplicate and tag photographed documents. |
| [Services](https://edu-fpar.github.io/services/) | Computer science teachers | Teaching "vibe coding" with APIs. |

### 🇫🇷 En français

**Des outils pour enseigner autrement : on manipule, on essaie, on comprend.**
Créés avec l'aide de l'IA par un formateur, pour les enseignants, les formateurs et leurs élèves. Tout fonctionne dans le navigateur, sans installation ni compte.

| Outil | Pour qui | Ce qu'on apprend |
|---|---|---|
| [Star Nav](https://edu-fpar.github.io/star-nav/#level-1) | Enfants dès 8 ans, parents, professeurs des écoles | La gravité et les trajectoires, sans une seule équation : 25 niveaux de navigation spatiale. |
| [MicroLearn Studio](https://edu-fpar.github.io/micro-learning-app/) | Formateurs, concepteurs de cours | Transformer un cours Markdown en diaporama interactif, exportable en SCORM. |
| [Regards croisés](https://edu-fpar.github.io/perspective-grid/) | Enseignants de toutes disciplines | Comment plusieurs points de vue classent différemment les mêmes éléments. Une grille se crée avec n'importe quelle IA. |
| [Capital Lab](https://edu-fpar.github.io/capital-lab/) | Écoles de commerce, finance, droit des sociétés | Comment on peut contrôler une société en étant minoritaire : chaînes de participations, pactes, droits de vote double. |
| [Mes photos de famille](https://edu-fpar.github.io/docs-badge/) | Généalogistes, enseignants qui annotent des copies scannées | Trier, dédoublonner et étiqueter des documents photographiés. |
| [Services](https://edu-fpar.github.io/services/) | Enseignants en informatique | Enseigner le « vibe coding » avec des API. |
